# CHIP-2025-03 test vectors

The ASERT and tick vectors of CHIP-2025-03 "Faster Blocks for Bitcoin
Cash", unchanged from the `tests/asert` and `tests/ticks` directories of the
CHIP repository at commit `9c4b023`
(https://gitlab.com/0353F40E/fablous), as gcash/bchd#775 carries them in
`blockchain/testdata/chip202503/`. The vectors are published under the MIT
No Attribution license.
